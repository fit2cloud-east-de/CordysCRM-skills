# 转换流程

线索转客户（可同时创建商机）。转换后自动补全联系人的电话和邮件。

---

## 步骤 1：确认转换方式

问用户：只转客户，还是同时创建商机？

## 步骤 2：校验目标模块必填字段

1. `cordys_ext.sh form clue` 获取线索字段列表
2. `cordys_ext.sh form account`（转客户）或 `cordys_ext.sh form opportunity`（转商机）获取目标模块必填字段
3. 目标必填字段中，与线索同名的字段会自动继承；不同名的即为缺失项，提示用户补充

## 步骤 3：执行转换

```bash
cordys_ext.sh transform '{"clueId":"<线索ID>","oppName":"<商机名>","contactName":"<联系人姓名>","phone":"<手机>","电话":"<座机>","电子邮件":"<邮箱>"}'
```

参数说明：
- `clueId`（必填）：线索 ID
- `oppName`：商机名称，传了就同时创建商机，不传则只转客户+联系人
- `contactName` + `phone`：用于转换后定位联系人并补全缺失字段
- `电话`、`电子邮件`：转换时不会自动带入联系人，通过此参数补全

> 注意：转换 API 不校验目标模块必填字段，缺的会留空。所以必须在转换前让用户确认。
