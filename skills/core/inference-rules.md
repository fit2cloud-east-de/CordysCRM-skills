# 智能推断规则

提取用户输入后，应用以下规则自动补充字段。这些规则是必须执行的。

## 产品简称转换

如果用户用了简称，转换为完整产品名：

| 用户说 | 转换为 |
|--------|--------|
| MS | MeterSphere 企业版 |
| JMS 或 JS | JumpServer 企业版 |
| MK | MaxKB 专业版 |
| DE | DataEase 专业版 |
| SQL 或 SB | SQLBot 专业版 |
| CRM 或 CD | Cordys CRM 企业版 |
| 1P | 1Panel 专业版 |
| KO | KubeOperator 容器平台 |
| CE | CloudExplorer 云管平台 |

> MaxKB 和 DataEase 默认"专业版"，其他产品默认"企业版"。

## 区域推断（根据省市自动填充区域）

如果用户提供了省市但没说区域，按以下规则填充：

- **北区**：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、山东、河南、陕西、甘肃、青海、宁夏、新疆
- **东区**：上海、江苏、浙江、安徽、江西、俄罗斯、白俄罗斯、哈萨克斯坦
- **南区**：广东、福建、湖北、湖南、广西、海南、重庆、四川、贵州、云南、西藏、香港、澳门、台湾、印度尼西亚、沙特阿拉伯
- **KA / 凌霞软件**：不能自动推断，必须用户明确指定

## 行业推断（根据公司名关键词自动填充行业）

如果用户没说行业，根据公司名猜测：

- 含"科技""网络""软件""信息""数据""智能" → 高科技和互联网
- 含"银行" → 银行
- 含"证券""基金""保险" → 非银金融
- 含"制造""工业""机械" → 制造
- 含"医院""医药""医疗" → 医疗
- 含"学校""大学""学院" → 教育
- 含"地产""建筑""置业" → 建筑和房地产
- 含"能源""电力""电网" → 能源和电力
- 含"物流""运输""航空" → 交通和物流

> 推断结果仅作为自动填充，如果用户明确指定了不同的值，以用户为准。

## 省市格式规范

用户提到城市时，转换为标准格式：

- 国内：`中国-XX省-XX市`（如用户说"杭州" → `中国-浙江省-杭州市`）
- 直辖市：`中国-XX市-XX区`（如用户说"北京海淀" → `中国-北京市-海淀区`）
- 国外：`国家-城市`（如 `印度尼西亚-雅加达`）

## 来源联动

- 如果来源/线索来源/客户来源是"线下"开头的（如"线下-合作伙伴"）→ 线上来源详情自动填 `线下不涉及`

## 默认值（通用）

- 有效合同额（商机）：未单独指定时，等于金额
- 是否已拜访（线索）：默认"否"
- 类型（客户）：默认"最终客户"
- 报备号/代签方名称（商机）：签约类型为"飞致云直签"时可为空
