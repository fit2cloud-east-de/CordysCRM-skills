# 查重流程

查重逻辑已脚本化，AI 只需调用命令并解读结果。无需提前读取其他文件或调用 whoami。

---

## 两种场景

| 场景 | 触发 | 参数 |
|------|------|------|
| 主动查重 | "查一下 xxx"、"有没有 xxx" | `场景` 不传或传 `"查重"` |
| 创建前查重 | 创建流程步骤 2 | `"场景":"创建"` |

---

## 调用方式

```bash
# 主动查重
cordys_ext.sh check '{"客户名":"<公司名>","手机":"<手机号>","产品":["<产品名>"]}'

# 创建前查重
cordys_ext.sh check '{"客户名":"<公司名>","手机":"<手机号>","产品":["<产品名>"],"场景":"创建"}'
```

参数说明：
- `客户名`：必填
- `手机`：选填
- `产品`：选填（主动查重时可不传，粗略判断；创建时必须传，精确判断）
- `场景`：选填，`"查重"`（默认）或 `"创建"`
- `currentUser`：选填，不传则自动获取

---

## 返回格式

### 主动查重模式

```json
{
  "info": { "线索": [], "线索池": [], "客户": [], "公海": [], "商机": [], "联系人": [] },
  "judgment": {
    "has_duplicate": true/false,
    "findings": ["描述1", "描述2"],
    "notices": ["提醒1"]
  }
}
```

- `has_duplicate: true` → 存在重复
- `findings` — 重复情况描述（他人线索/商机/保护期）
- `notices` — 线索池/公海/联系人提醒

### 创建前查重模式

```json
{
  "info": { ... },
  "judgment": {
    "pass": true/false,
    "blocks": [{"rule": 1, "message": "..."}],
    "warnings": [{"rule": 3, "message": "..."}],
    "note": "以上判断仅供参考，请结合实际情况决定"
  }
}
```

- `pass: false` → 存在阻断冲突，展示 blocks 问用户是否继续
- `warnings` → 提醒，不阻断

```
| 名称 | 负责人 | 部门 | 产品 | 阶段 | 创建时间 | 最近跟进 | 赢单时间 |

---

### 重复判断（仅供参考）

（has_duplicate 为 true 时：列出 findings，每条用 · 前缀）
（has_duplicate 为 false 时：未发现重复记录）
（notices 不为空时：列出，每条用 ℹ 前缀）
```

### 创建前查重

```
### 查重判断

（pass 为 true 时：✅ 未发现冲突，可以创建）
（pass 为 false 时：⛔ 存在冲突：列出 blocks 的 message）
（warnings 不为空时：⚠️ 前缀列出）
```

---

## 注意事项

- 所有 6 个分类必须展示，空的写"无"
- null 字段显示 `-`
- 不要自行添加额外的总结或建议段落
- 不要改变分类顺序
- 主动查重不使用"阻断"字眼
