# 线索 → 商机 字段映射

线索转客户并创建商机（`cordys_ext.sh transform` 带 `oppName`）时，"线索/客户字段→商机字段"的映射、默认值、需补充项。
**本文件是转化建商机时字段映射与默认值的唯一权威源**；转化流程 `core/write-engine.md §5` 指向这里。

> `cordys_ext.sh transform` 传**中文字段名/中文值**（内部自动转 ID、转化后自动补全商机字段），不用 fieldId 双层结构。

> 转换 API（`/lead/transform`）不校验商机必填字段，缺的会留空——映射和默认值必须在转化前按本表补齐。

---

## 自动继承（直接沿用线索的值，**不要再问用户**）

| 线索字段 | 商机字段 | 说明 |
|---------|---------|------|
| 客户名（公司） | 客户名 | 转化后指向新建客户 |
| 区域 | 区域 | 沿用 |
| 行业 | 行业 | 沿用 |
| 线索来源 | 来源 | 线索"来源"映射到商机"来源" |
| 线上来源详情 | 线上来源详情 | 沿用 |
| 省市 | 省市 | **行政代码原样继承**（如 `3413-`），线索有就不重新问用户、不重新查 `loc` |
| 产品 | 产品类型（可多选） | 沿用意向产品 |

> ⚠️ 上表字段只要线索里有值，一律继承，**不得列为缺失项向用户索取**。

---

## 默认值（用户未指定时自动填充，展示确认时可改）

| 商机字段 | 默认值 | 说明 |
|---------|--------|------|
| 签约类型 | 飞致云直签 | 可选值：飞致云直签 / 商务平台代签 / 盟军代签 等。**未指定用默认，绝不当缺失项问用户** |
| 有效合同额 | = 金额 | 未单独指定时等于金额 |
| 最终用户工商全称 | = 客户名 | 未单独指定时等于客户名/公司名，不问用户；旧参数名「最终用户全称（工商可查）」仅作兼容别名 |

---

## 商机名（自动生成，展示确认，不当缺失项问）

按 `sop/inference-rules.md` 的"商机名自动生成"规则生成：
`最终用户简称-产品简称-年份-服务类型+业务机会类型`，如 `华星-MK-2026-订阅新购`。
自动生成后在确认表里展示，用户可改，**不要当缺失字段单独问"商机名简称"**。

---

## 需向用户补充的字段（线索没有、无默认、无法推断的）

对照 `references/forms/opportunity.md` 必填清单，扣除上方继承/默认/自动生成后，通常**只剩这几项**需问用户：

1. 金额（预计合同金额）
2. 结束日期（预计签约日期，如 2026-12-31）
3. 服务类型：订阅 / 授权 / 服务 / 维保 / 一体机
4. 业务机会类型：新购 / 续费 / 维保 / 扩容

> **条件必填**：按 `references/forms/opportunity.md`「条件必填」列判断（如签约类型选了代签类，「报备号/代签方名称」才变必填）。默认"飞致云直签"不触发代签类必填，无需问报备号。
> **关键决策人（KP）**：可在转换后补充（联系人是转换时才创建的），不阻塞转化。
