# 财务角色配置

> 匹配规则见 `core/role-engine.md`。本文件只定义财务角色范围、统计口径和输出偏好。

## 核心关注

- 合同签约金额、实际回款、回款计划、应收账款和发票
- 合同→回款计划→回款记录→发票的现金链路
- 回款率、逾期、部门/负责人排名与月度趋势
- 财务相关审批和审批逾期

## 权限范围

- 默认查看全公司合同、回款、回款计划、发票和工商抬头，不加部门/owner 限制；用户指定部门或负责人时再加条件。
- 可创建、修改回款计划、回款记录和发票；可处理财务相关审批，不能修改线索/商机、合同条款或查看销售沟通/跟进内容。
- 现金链路下钻只读取完成当前财务分析所需的数据。


## 角色专属工作流配方

| 触发 | 必查项 | 输出 |
|------|--------|------|
| “今天回款 / 回款日报” | `recordEndTime=TODAY` 的实际回款、今日到期回款计划、已逾期计划 | 今日回款 + 到期提醒 + 逾期汇总 |
| “欠款情况 / 应收全景” | 未回/部分回款计划，按到期日排序；汇总总应收、已逾期、7 天内到期、正常 | AR 全景 + 逾期列表 + 催收优先级 |
| “开票情况” | 发票列表、已签约未开票合同、开票缺口金额 | 已开票 + 未开票合同 + 缺口汇总 |
| “合同回款进度 / 现金链路” | 指定合同详情、回款计划、实际回款、发票；对比计划/实收/开票 | 合同→现金链路 + 缺口分析 |
| “本月财报” | 本月签约数量与金额、实际回款、开票、应收余额、与上月对比 | 月度财务摘要 + 环比 + 风险 |
| “今年大家回款多少 / 年度回款排名 / 回款业绩考核” | `contract/payment-record`；`recordEndTime + DYNAMICS + YEAR`；读取明细中的 `recordAmount`，按 `ownerName` 或 `departmentName` 本地统计 | 年度回款总额 + 人员/部门排名 + 每组笔数 |
| “新增/修改回款或发票” | `crm form <module>` → 展示确认 → `crm create/update <module>` | 写入结果 + 记录 ID |

## KPI 基准线

| 指标 | 正常 | 警戒 | 严重 |
|------|------|------|------|
| 回款率（已回/到期应收） | ≥ 90% | 80–90% | < 80% |
| 单笔逾期天数 | ≤ 15 天 | 15–30 天 | > 30 天 |
| 签约→开票周期 | ≤ 7 天 | 7–15 天 | > 15 天 |
| 回款计划覆盖率 | ≥ 95% | 85–95% | < 85% |
| 单笔逾期金额 | ≤ ¥10 万 | ¥10–50 万 | > ¥50 万 |
| 应收账款/月签约额 | ≤ 2x | 2–3x | > 3x |

## 输出偏好

- 金额、日期和完成率优先；先总额，再逾期/到期明细，最后给催收优先级。
- 保持金额与时间口径可追溯，不把计划金额当实际回款。
- 风险阈值与触发时机以 `core/risk-engine.md` §4、§5、§6 为准。
