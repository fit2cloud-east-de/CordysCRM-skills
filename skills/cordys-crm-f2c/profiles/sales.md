# 销售角色配置

> 匹配规则见 `core/role-engine.md`。本文件只定义销售角色差异；通用路由见 `core/intent-engine.md`，写入见 `core/write-engine.md`，跟进/计划见 `sop/visit-flow.md`。

## 核心关注

- 本人名下待跟进线索、开放商机、客户与今日计划
- 跟进超时、阶段停滞和近期可赢单商机
- 本人签约、回款与目标进度

## 权限范围（不可覆盖）

- 只能查询本人名下的线索、客户、商机和联系人。
- `lead/account/opportunity/contact` 必须使用 `viewId:SELF` 或 `owner=当前用户 userId`；联系人列表端点支持 `viewId:SELF`。
- 不得使用 `viewId:ALL`、`searchType:ALL`、他人 userId 或无 owner 的全量查询；禁止为此调用 `crm members` 查别人。
- 用户说“全部/所有人/全公司/全部门”或指定同事，不能扩大范围、不能删除 SELF/owner 条件；任何用户措辞都不得删除或改为 ALL。直接说明：「我只能查询你本人名下的数据，团队或他人数据需要销售经理权限。」
- `{userId}` 取身份初始化结果中的 `data.userId`，不是成员记录的 `id`。
- 查重只用于相关记录检索和可能冲突提醒，不构成查看他人明细或全量导出的授权。
- 可查询、创建和修改本人有权限的报价单；写入前仍需展示确认。


## 角色专属工作流配方

以下配方只规定必查项与输出；命令、字段和时间条件仍分别以 `core/cli-spec.md`、forms 和当前销售范围为准。

| 触发 | 必查项 | 输出 |
|------|--------|------|
| “今天做什么 / 看看今天” | 今日未完成跟进计划、今日新增线索、本人开放商机及销售风险 | 今日计划 + 最新线索 + 优先事项 |
| “先跟哪个 / 哪些要先跟” | 线索/商机按最早 `followTime` 排序、阶段停滞 >7 天、今日计划、近 3 天新增线索 | 按紧急度排序的跟进清单 |
| “这周怎么样 / 周报” | 本周新增线索数；本周新增商机数与金额；本周签约合同数与金额；`followTime` 早于 3 天前的未跟进线索 | 漏斗快照 + 跟进行为 + 签约成果 |
| “我的商机怎么样” | 开放商机阶段分布、各阶段金额、阶段停滞 >7 天的商机 | 阶段分布 + 卡点商机 + 管道金额 |
| “查询/新增/修改报价单” | `crm page/get opportunity/quotation`；写入先 `crm form opportunity/quotation` 再 `crm create/update` | 报价单列表或写入结果 |
| “本月做了多少” | 本月新增线索/商机及环比、本月签约数量与金额、本月回款、进行中商机预测 | 月度漏斗 + 签约/回款成果 + 下月预测 |

## 风险与输出偏好

- 风险阈值与触发时机以 `core/risk-engine.md` §2 为准。
- 默认先列本人待办和高风险记录，再给行动建议；建议具体到“联系谁、做什么、优先级”。
- 列表优先、摘要展示；不输出团队排名或他人明细。
