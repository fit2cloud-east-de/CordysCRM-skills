# 高管角色配置

> 匹配规则见 `core/role-engine.md`。本文件只定义高管角色的公司级范围、指标口径和输出偏好。

## 核心关注

- 全公司 L2C 漏斗、季度/年度目标、签约与回款趋势
- 部门/产品线贡献、组织效能和管道预测
- 应收账款、回款率、大额逾期与结构性风险

## 权限范围

- 查询范围是全公司，不使用部门过滤或 `viewId:SELF`。
- 默认只到公司/部门汇总层，不下钻具体成员、客户、跟进内容或单条记录。
- 高管角色只读：不得创建、修改、分配、转化或执行其他 CRM 写操作。
- 查看公司/某单全景时使用 `core/linkage-engine.md`，仍遵守汇总层级边界。

## 指标口径

| 场景 | 口径/入口 |
|------|-----------|
| 公司 L2C 漏斗 | `core/funnel-engine.md`，全公司范围 |
| 签约/回款/应收 | `core/cli-spec.md` §10 + 对应 forms 字段口径 |
| 部门排名 | 按一级部门聚合，不输出未请求的个人明细 |
| 管道预测 | 进行中商机金额 × 有依据的阶段历史转化率；无转化率数据时不得编造 |
| 人效 | 签约/回款等总指标 ÷ 对应范围成员数 |
| 趋势/环比/同比 | 使用可比时间范围和相同业务字段 |

## 角色专属工作流配方

所有配方只输出公司/部门汇总，不下钻个人或单条业务记录。

| 触发 | 必查项 | 输出 |
|------|--------|------|
| “公司情况 / 经营快照” | 全公司线索、商机数量与金额、赢单、签约金额及可比期变化 | 核心经营卡片 + 环比 + 异常 |
| “这周全公司 / 部门怎么样” | 本周签约汇总、一级部门排名、周环比、偏差 >30% 的部门 | 签约排名 + 环比 + 异常部门 |
| “目标完成怎么样” | 季度签约与目标、时间进度与业绩进度、商机管道预测 | 完成率 + 目标差距 + 预测 |
| “本月经营数据” | 全公司 L2C 漏斗、签约/回款/开票、同比或环比、目标缺口 | 月度经营报告 + 趋势 + 缺口 |
| “下季度预测” | 当前管道金额、阶段分布、有依据的历史转化率、下季目标 | 预计产出 + 目标覆盖率 |
| “人均产出 / 人效” | 总签约额、销售人数、部门人效与环比 | 人均产出 + 部门排名 + 趋势 |
| “Q2 复盘 / 季度复盘” | 本季度 L2C 漏斗、上季度和去年同季对比、部门贡献占比、赢单/输单原因分布 | 季度对比 + 趋势 + 部门占比 |
| “今年全年 / 年度总结” | 12 个月逐月签约趋势、12 个月逐月回款趋势、部门年度贡献占比、年度 L2C 漏斗 | 年度趋势 + 部门占比 + 里程碑 |

## KPI 基准线

| 指标 | 正常 | 警戒 | 严重 |
|------|------|------|------|
| 季度目标进度 vs 时间进度 | 偏差 ≤ 10% | 10–20% | > 20% |
| 部门签约环比波动 | ≤ 20% | 20–30% | > 30% |
| 全公司回款率 | ≥ 90% | 80–90% | < 80% |
| 应收账款/月签约额 | ≤ 2x | 2–3x | > 3x |
| 大额逾期（>¥50万且>30天） | 0 | 1–2 | ≥ 3 |
| 人均月签约额 | ≥ ¥30 万 | ¥15–30 万 | < ¥15 万 |
| 线索→合同转化率 | ≥ 5% | 3–5% | < 3% |

## 输出偏好

- 先结论，再汇总、趋势、异常和决策建议；能用对比表就不用长段文字。
- 默认展示公司→部门两层，不展示单条明细。
- 关注偏离度、趋势拐点和结构性调整；风险规则见 `core/risk-engine.md` §6、§7。
