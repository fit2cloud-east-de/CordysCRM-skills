# 商务 / 合同管理角色配置

> 匹配规则见 `core/role-engine.md`。本文件只定义商务/合同角色的范围、合同口径和输出偏好。

## 核心关注

- 合同状态、条款、审批进度、驳回原因、到期续约和附件完整性
- 报价→合同→开票的流程衔接
- 审批周期、驳回率、到期风险和大额合同

## 权限范围

- 可查看全部合同、合同审批流、工商抬头、发票和合同上游报价单。
- 不能修改线索/商机、执行回款、查看无关销售数据或非关联跟进记录。
- 审批副作用操作仍受全局二次确认约束，不因本角色而放宽。

## 合同口径

| 场景 | 口径/入口 |
|------|-----------|
| 审批中的合同/审批进度 | `core/cli-spec.md` §13 + `core/cli-reference.md` §4 |
| 本期签约 | 合同时间字段按 `references/forms/contract.md` 选择，不混用创建时间与开始时间 |
| 即将到期/续约 | `endTime BETWEEN [now, now+窗口]`，按结束时间升序 |
| 合同详情/完整性 | 合同详情 + 审批记录 + 附件；跨模块一致性用 `core/linkage-engine.md` |
| 合同统计 | `core/cli-spec.md` §10；金额用 `contract.amount` |

## 角色专属工作流配方

| 触发 | 必查项 | 输出 |
|------|--------|------|
| “审批到哪了 / 合同审批” | 合同待审批列表、每条当前节点与持续时间 | 审批中合同 + 当前节点 + 等待时长 |
| “今天签了什么” | 今日签约合同列表、数量与金额 | 今日签约 + 金额汇总 |
| “被驳回的” | 驳回合同、驳回原因与次数，按次数排序 | 驳回列表 + 原因 + 处理建议 |
| “本周签约汇总” | 本周签约数量与金额、部门分布、客户分布 | 签约概览 + 部门/客户分布 |
| “哪些快到期 / 续约” | `endTime BETWEEN [now, now+30天]`，按到期日升序 | 30 天内到期合同 + 客户/金额 + 续约建议 |
| “下月到期合同 / 续约扫描” | `endTime BETWEEN [now+30天, now+60天]`，按客户汇总并标记续约意向 | 未来 30–60 天到期合同 + 客户 + 续约建议 |
| “本月签约月报” | 本月签约数量与金额、环比、合同类型、平均审批周期 | 签约趋势 + 类型分布 + 审批效率 |
| “合同完整性检查” | 盖章、附件、审批记录、合同金额与商机金额一致性 | 合规清单 + 问题合同 |

## KPI 基准线

| 指标 | 正常 | 警戒 | 严重 |
|------|------|------|------|
| 合同审批周期 | ≤ 3 天 | 3–7 天 | > 7 天 |
| 合同到期提前关注 | ≥ 60 天 | 30–60 天 | < 30 天 |
| 合同驳回率 | ≤ 10% | 10–20% | > 20% |
| 签约后开票触发 | ≤ 3 天 | 3–7 天 | > 7 天 |
| 合同附件完整率 | 100% | < 100% | — |

## 输出偏好

- 合同状态和日期优先，审批节点次之，金额辅助。
- 输出顺序：待处理/风险结论 → 合同列表 → 审批或到期细节 → 催办/续约建议。
- 强调流程完整性与条款风险；审批、跨模块和商务风险见 `core/risk-engine.md` §5、§6、§8。
