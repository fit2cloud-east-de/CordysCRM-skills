# 查重流程

查重通过 `cordys_ext.sh check` 调用，返回结构化结果后解读。

---

## 调用方式

```bash
cordys_ext.sh check '{"客户名":"<公司名>","手机":"<手机号>","产品":["<产品名>"]}'
```

参数说明：
- `客户名`：客户名或手机号**至少填一个**（都不填报错）。给了人名也放这里
- `手机`：客户名或手机号至少填一个。**只给手机号也能查**（按手机号并行搜 线索/商机/联系人/线索池）
- `产品`：选填（传了可精确判断产品冲突，不传则粗略判断）

> **重要**：用户提到产品（如"查一下 xxx 有没有 MaxKB"）必须将产品传入 `产品`，用完整名（"MaxKB 专业版"而非"MK"）。

> **意图识别（客户名 vs 产品）**：
> - **产品**：固定列表（见各表单 SELECT「产品类型」）+ 简称——JS/JMS=JumpServer、MK=MaxKB、MS=MeterSphere、DE=DataEase、1P=1Panel 等（见 `sop/inference-rules.md`）
> - **客户名**：公司/组织名
> - 例："畅联智融有没有 MK" → 客户名=畅联智融、产品=MaxKB 专业版
> - 不确定时只传客户名，不要把产品名当客户名
> - 「的+产品」消歧细则见 `profiles/sales.md`

## 返回格式

```json
{
  "display_order": ["线索","线索池","客户","公海","商机","联系人"],
  "info": {
    "线索": [{"name":"...","owner":"...","department":"...","products":["..."],"phone":"...","followTime":"2026-05-14"}],
    "线索池": [{"name":"...","products":["..."],"phone":"...","pool":"..."}],
    "客户": [{"name":"...","owner":"...","department":"...","createTime":"...","followTime":"..."}],
    "公海": [{"name":"..."}],
    "商机": [{"name":"...","owner":"...","department":"...","products":["..."],"stage":"...","createTime":"...","followTime":"...","winTime":"..."}],
    "联系人": [{"name":"...","customer":"...","owner":"...","phone":"..."}]
  },
  "judgment": {
    "conflicts": [{"rule": 1, "message": "..."}],
    "warnings": [{"rule": 3, "message": "..."}]
  }
}
```

- `conflicts` — 规则命中的冲突（产品重复、线索池/公海同名、手机号重复等）
- `warnings` — 提醒（线索池同名、公海同名、联系人手机重复等）

## AI 展示指引

**格式为硬性约束，不得自行替换为摘要、叙述或自定义表格。**

- **必须**按上方模板完整输出 6 个分类，无记录的分类写"无"，不得省略任何分类
- null 字段显示 `-`
- 分类顺序**必须**遵循 display_order：线索→线索池→客户→公海→商机→联系人
- 每个分类**必须**用规定的表头（见模板），不得改成"项目/详情"或其他自定义结构
- 主动查重时：客观陈述冲突事实，不使用"禁止""阻断"等强制性字眼
- 创建前查重时：conflicts 不为空应明确提醒用户存在冲突，询问是否继续
- **严禁**在规定模板之外追加任何总结、背景介绍、个人判断或建议段落（如"是老客户了""关系稳得很""不是你的客户"等补充描述一律不写）

## 规则说明

| 规则 | 触发条件 | 严重程度 |
|------|---------|---------|
| 1 | 他人线索/开放商机存在相同产品 | conflict |
| 3 | 线索池手机号相同 / 公海同名 | conflict |
| 3 | 线索池同名 | warning |
| 4 | 无线索无商机但联系人手机重复 | warning |
| 5 | 手机号已存在于线索中（后端拒绝重复） | conflict |
