# 跟进方式映射

> 传值规则：传数字 ID（value 列），不是中文标签。

## followMethod 选项

| value | label | 用户表达 |
|-------|-------|---------|
| `1` | 到访 | "线下拜访""上门""面谈""去了""去" |
| `2` | 电话 | "线上拜访""电话""远程""打了个电话" |
| `176776376843300000` | 微信 | "微信""微信上聊" |
| `176092552150400000` | 邮件 | "邮件""发邮件" |
| `175375487193300000` | 线上会议 | "视频会议""线上会议""远程会议" |

## 默认值

| 场景 | 默认 followMethod | 理由 |
|------|------------------|------|
| 拜访（线下） | 1（到访） | "拜访"即线下上门 |
| 拜访（线上） | 2（电话） | 线上沟通默认电话 |
| 纯跟进 | 2（电话） | "跟进"不含"拜访"，默认远程沟通 |

> 不要对纯跟进场景传 1（到访），到访意味着线下见面，和"跟进"矛盾。

> "线上拜访"指电话/语音沟通（followMethod=`2`），"线上会议"指视频会议（followMethod=`175375487193300000`）。用户说"远程"默认按电话处理。
